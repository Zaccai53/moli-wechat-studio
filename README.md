# 墨流 · 微信公众号排版工作台

一个本地优先的微信公众号排版、转载加工与发布工具。目前优先实现可直接嵌入公众号编辑页的 Chrome 扩展，`public/` 下的独立网页是早期验证原型。

## 推荐使用：Chrome 扩展

进入 Chrome 的 `chrome://extensions/`，打开开发者模式，选择“加载已解压的扩展程序”，然后选择本项目的 `extension` 文件夹。详细说明见 [`extension/README.md`](extension/README.md)。

## 启动

需要 Node.js 18 或更高版本，无需安装第三方依赖：

```bash
npm start
```

然后访问 `http://localhost:4173`。

## 已实现

- 导入 Markdown / TXT，或直接粘贴文本
- 实时解析标题、列表、引用、代码块、表格与图片
- 三套公众号文章风格、字号/行距/内容宽度调节
- 复制富文本后直接粘贴到公众号后台
- 本地自动保存与草稿快照（`⌘S` / `Ctrl+S`）
- 导入 `mp.weixin.qq.com` 文章并在文首/文末加入编者按
- 通过公众号官方接口创建草稿，并按需提交发布

## 配置公众号接口

AppSecret 不会发送到浏览器。启动时通过服务端环境变量配置：

```bash
WECHAT_APP_ID=你的AppID \
WECHAT_APP_SECRET=你的AppSecret \
npm start
```

公众号后台还需配置当前服务器出口 IP 白名单。创建草稿时需要填写永久封面素材的 `media_id`。自动发布能否使用取决于公众号账号类型、认证状态和官方接口权限。

## 使用边界

转载导入仅接受 `https://mp.weixin.qq.com` 链接。工具不会绕过转载限制，使用者需要先获得原作者或平台授予的转载及修改权限。部分公众号文章包含视频、小程序卡片或特殊 SVG，这些内容在导入后可能需要在公众号后台再次确认。
