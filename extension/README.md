# 墨流 Chrome 扩展

## 本地加载

1. 打开 Chrome 的 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目的 `extension` 文件夹。
5. 打开或刷新微信公众号图文编辑页，右下角会出现“墨流”按钮。

## 原生转载流程

### 从公众号首页开始（点击最少）

1. 在公众号首页“新的创作”区域，直接点击带有“墨流自动配置”标记的“转载”；也可以点击右下角“墨流转载”。
2. 在微信原生窗口中搜索并选中文章，点击“确定”。
3. 进入编辑页后，墨流会自动展开“转载”配置；确认默认增补设置后点击“应用到原生转载”。若原文尚未选择，点击公众号的“转载”后会自动续接并完成增补。

### 从编辑页开始

1. 在墨流的“转载”页粘贴原文链接，点击“在公众号转载窗口中搜索”。
2. 墨流会自动沿“新建内容 → 转载文章”（或页面上的直接“转载”入口）打开转载窗口并搜索原文；点击“应用到原生转载”时若尚未选择原文，也会先执行这一步。
   若公众号提示“不是有效的账号原创文章链接”，且你已勾选单独授权，关闭转载窗口后墨流会自动改用公开正文直导。
3. 回到公众号窗口选择文章并点击“确定”。
4. 再次打开墨流：扩展会显示“转载可修改”或“仅可荐语”。
5. 填写荐语和正文增补内容，点击“应用到原生转载”。

原生转载是推荐路径：原文图片、出处和授权状态都由微信自身处理。若原作者没有授予修改权限，扩展不会尝试修改正文，只填写官方荐语。

增补内容支持：

- 文首自动添加“以下文章来源于公众号名称，作者作者名”；若微信已经生成原生来源介绍，则自动跳过或清理重复署名
- 文末添加一张本地图片，并优先交给公众号粘贴上传逻辑处理
- 标题添加“活动推荐 |”前缀，或改成自定义标题

这些增补项会自动保存为浏览器本地默认设置；原文链接不会保存。结尾图片也会尝试持久化，过大的图片会只在当前面板会话中保留。

对于不可修改的原创文章或无法走原生转载的非原创文章，只有明确确认已获得作者单独授权后，才可以使用“公开正文直导”转成普通新文章。
公开正文直导会以编辑器中的实际标题、正文和图片节点判断是否写入成功；即使微信清空了编辑区，再次点击也会重新写入，而不会被旧缓存标记误判为已完成。

扩展不读取或保存公众号登录 token，也不会绕过公众号的权限和发布确认。正文排版发生在当前页面；点击“保存为草稿”会触发公众号页面原有按钮；点击“进入发表确认”只打开公众号自身的发表流程。

## 已适配的 2026 编辑器结构

- 标题：`#js_title_main .title-editor-overlay .ProseMirror`
- 正文：`#ueditor_0 .rich_media_content .ProseMirror`
- 旧版正文兜底：`#edui1_iframeholder iframe` 内的可编辑节点
- 原生转载搜索：`.share_article_dialog .js_search_input`
- 原生转载状态：`#js_reprint_source` 与 `#js_reprint_article_tips`
- 原生转载荐语：`.js_reprint_recommend_title` 与 `.js_reprint_recommend_content`
- 保存草稿：`#js_submit`
- 发表入口：`#js_send`

## 当前限制

- Markdown 中的远程图片会写入正文，但公众号是否完成转存需在首次保存前人工确认。原生转载不受此限制。
- 视频、小程序卡片、投票等公众号专属组件不会从公开转载文章中复制。
- 公开链接导入等同于“复制并修改原文”；只有获得相应版权许可时才应使用。若公众号已经提供原生转载权限，应优先使用“增强原生转载”。
